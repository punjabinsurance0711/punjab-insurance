# Punjab Insurance Website

Production-ready starter for Punjab Insurance.

## Stack
- Next.js 16
- React 19
- TypeScript
- Responsive custom CSS
- English / Punjabi homepage
- User-provided office photos

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy
Import this GitHub repository into Vercel. Vercel supports zero-configuration Next.js deployment and automatic deployments from connected Git repositories.

## Before launch
- Add Kamalpreet Kaur professional photo.
- Replace carrier text boxes with approved official carrier logos after confirming permission/brand requirements.
- Connect a production quote-form/email provider.
- Add finalized Privacy Policy and Terms after review.
- Connect www.punjabinsuranceagency.com in Vercel.
